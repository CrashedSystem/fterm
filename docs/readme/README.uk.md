## Termux, чесно кажучи, незручний

- Щоб змінити шрифт, колір або одну зайву клавішу внизу, доводиться відкривати файл конфігурації (`termux.properties`).
- Щоб перемкнути вкладку, щоразу треба свайпати бічну панель зліва.
- У повноекранних інтерфейсах (TUI) на кшталт OpenCode клавіатура інколи просто не відкривається.
- Корейська та інші мови з'їжджають, а вставити скриншот у промпт — справжня морока.
- Під час вставлення великого тексту все підвисає, а переноси рядків розсипаються на окремі Enter.
- Навіть одне сповіщення про завершення роботи потребує окремо встановленого `termux-api`.

## fterm почався саме з цього

Оболонка лишилася тією ж, з Termux, — **заново зроблено тільки екран і введення, які дратували.**

- **Вкладки перед очима**: відкривайте, перемикайте, перейменовуйте й розфарбовуйте вкладки просто у верхній панелі, без свайпів.
- **Налаштування без файлів конфігурації**: кольорові теми, шрифти (корейська та іконки вже всередині), фонові зображення й нижня панель клавіш змінюються в налаштуваннях самого застосунку.
- **Готові профілі**: виберіть оболонку чи команду, якою користуєтеся найчастіше, і відкривайте її одразу.
- **Сучасний інтерфейс, на який приємно дивитися**: охайні іконки Fluent, вкладки у стилі Windows Terminal і CRT-ефект за бажанням — нічого дерев'яного.
- **Безпечне вставлення (bracketed paste)**: багаторядковий код вставляється без зайвих Enter, а на тексті понад 5 КБ застосунок один раз перепитає, щоб не вставити випадково.
- **Копіювання, посилання й зображення в TUI — в одному місці**:
  - Під час копіювання пробіли в кінці рядків прибираються самі.
  - Одне торкання зображення в буфері обміну зберігає його як PNG і підставляє шлях.
  - Утримуйте `Ctrl` і торкніться URL на екрані — він відкриється в браузері.
- **Сповіщення без зайвих застосунків і 13 мов**: дзвінок і сповіщення працюють без `termux-api`, інтерфейс підтримує 13 мов.
- **Відновлення у фоні**: закрийте застосунок і поверніться — екран і режим миші на місці.

## Встановлення

Потрібно лише три речі: **встановити APK**, **виконати один рядок у Termux** і **дозволити 3 дозволи**.

1. Завантажте **`fterm.apk`** з [Releases](https://github.com/CrashedSystem/fterm/releases/latest) і встановіть.
2. Відкрийте **Termux** і вставте рядок нижче, щоб виконати його.

```bash
curl -fsSL https://raw.githubusercontent.com/CrashedSystem/fterm/master/termux/setup.sh | bash
```

3. Запустіть **fterm** і дозвольте три запитані дозволи.
   - **Доступ до всіх файлів**: щоб застосунок обмінювався токеном із демоном Termux.
   - **Фото/зображення**: щоб вставляти скриншоти з буфера обміну.
   - **Сповіщення**: щоб дзвеніло по завершенні роботи.

Щойно дозволите й повернетеся в застосунок, з'єднання встановиться саме.

## Корисні комбінації

- **Нова вкладка / закрити вкладку**: кнопка `+` / довге натискання на вкладку (клавіатура `Ctrl+Shift+T` / `W`)
- **Відкрити налаштування**: довге натискання на `+` (`Ctrl+,`)
- **Перемикання вкладок**: `Ctrl+Tab` / `Ctrl+1–9`
- **Відкрити URL одразу**: `Ctrl` + торкання або клік по екрану
- **Копіювати / вставити**: `Ctrl+Shift+C` / `V`, або довге натискання · права кнопка миші
- **Розмір тексту**: `Ctrl+=` / `Ctrl+-` / `Ctrl+0`

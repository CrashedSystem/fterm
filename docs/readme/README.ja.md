## 正直、従来のTermuxはちょっと使いにくい

- フォントや色、下部の追加キーをひとつ変えるだけでも、設定ファイル（`termux.properties`）を開かないといけません。
- タブを切り替えるたびに、毎回左端からサイドバーをスワイプする必要があります。
- OpenCodeのような画面（TUI）を使っていると、キーボードが開かないことがときどきあります。
- 日本語や多言語の表示がずれて、スクリーンショット画像をプロンプトに入れるのも面倒です。
- 長いテキストを貼り付けるとカクつき、改行がEnterに分解されて飛んでいきます。
- 作業が終わったときに通知をひとつ受け取るだけでも、`termux-api`を別に入れなければなりません。

## ftermはそこから始まりました

シェルはすでに慣れているTermuxのものをそのまま使い、**不便だった画面と入力だけを一から作り直しました。**

- **ひと目でわかるタブバー**: サイドスワイプなしで上からすぐにタブを開き、切り替え、名前や色まで選べます。
- **設定ファイルなしでそのままカスタマイズ**: カラーテーマ、フォント（日本語・アイコンは標準搭載）、背景画像、下部キーバーまで、アプリ内の設定画面からすぐに変えられます。
- **用意されたプロフィール**: よく使うシェルやコマンドをプロフィールとして選び、すぐに開けます。
- **モダンで見やすいインターフェース**: すっきりしたFluentアイコンとWindows Terminal風のタブUI、好みでオンにできるCRT効果まで備え、堅苦しくありません。
- **安全な貼り付け（ブラケットペースト）**: 複数行のコードを貼り付けてもEnterが勝手に押されず、5KB以上の大きなテキストは誤操作しないよう一度確認してから貼り付けます。
- **TUIのコピー・リンク・画像までまとめて**:
  - コピー時に各行末尾の空白は自動で取り除きます。
  - クリップボードの画像をワンタップでPNG保存し、パスを自動入力します。
  - `Ctrl`を押しながら画面のURLをタップすると、ブラウザで直接開きます。
- **追加アプリなしの通知 & 13言語**: `termux-api`なしでもベル音と通知が鳴り、アプリの表示言語は13言語に対応しています。
- **バックグラウンド復元**: アプリを閉じて開き直しても、実行中だった画面とマウスモードがそのまま残ります。

## インストール方法

必要なものはシンプルです。**APKのインストール**、**Termuxでの1行実行**、そして**権限3つの許可**。

1. [Releases](https://github.com/CrashedSystem/fterm/releases/latest)から**`fterm.apk`**をダウンロードしてインストールします。
2. **Termux**を開き、下の1行を貼り付けて実行します。

```bash
curl -fsSL https://raw.githubusercontent.com/CrashedSystem/fterm/master/termux/setup.sh | bash
```

3. **fterm**を起動し、求められる3つの権限を許可してください。
   - **すべてのファイルへのアクセス権限**: アプリがTermuxデーモンとトークンをやり取りするために必要です。
   - **写真/画像の権限**: クリップボードのスクリーンショットを貼り付けるために必要です。
   - **通知の権限**: 作業完了のベル通知を表示するために必要です。

権限を許可してアプリに戻ると、自動的に接続されます。

## よく使うショートカット

- **新しいタブ / タブを閉じる**: `+`ボタン / タブを長押し（キーボード `Ctrl+Shift+T` / `W`）
- **設定を開く**: `+`を長押し（`Ctrl+,`）
- **タブ移動**: `Ctrl+Tab` / `Ctrl+1~9`
- **URLをすぐ開く**: `Ctrl` + 画面をタップまたはクリック
- **コピー / 貼り付け**: `Ctrl+Shift+C` / `V`、または画面を長押し・右クリック
- **文字サイズ**: `Ctrl+=` / `Ctrl+-` / `Ctrl+0`

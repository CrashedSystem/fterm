## 기존 Termux, 솔직히 좀 불편합니다

- 폰트, 색상, 하단 추가 키 하나 바꾸려고 설정 파일(`termux.properties`)을 열어야 합니다.
- 탭을 바꾸려면 매번 왼쪽에서 사이드바를 스와이프해야 합니다.
- OpenCode 같은 화면(TUI)을 쓰다 보면 키보드가 간헐적으로 안 열릴 때가 있습니다.
- 한글이나 다국어가 어긋나고, 스크린샷 이미지를 프롬프트에 넣기도 번거롭습니다.
- 긴 텍스트를 붙여넣으면 버벅이거나 줄바꿈이 엔터로 쪼개져 날아갑니다.
- 작업 끝났을 때 알림 하나 받으려고 `termux-api`를 따로 깔아야 합니다.

## fterm은 거기서 출발했습니다

셸은 이미 익숙한 Termux 것을 그대로 쓰고, **불편했던 화면과 입력만 싹 갈아엎었습니다.**

- **한눈에 보이는 탭 바**: 사이드 스와이프 없이 위에서 바로 탭을 열고, 바꾸고, 이름·색까지 고릅니다.
- **설정 파일 없이 바로 커스터마이징**: 색상 테마, 폰트(한글·아이콘 기본 내장), 배경 이미지, 하단 키 바까지 앱 안의 설정 화면에서 바로 바꿉니다.
- **미리 준비된 프로필**: 자주 쓰는 셸이나 명령을 프로필로 골라 바로 엽니다.
- **모던하고 보기 편한 인터페이스**: 깔끔한 Fluent 아이콘과 Windows Terminal 스타일의 탭 UI, 원하면 켤 수 있는 CRT 효과까지 넣어 딱딱하지 않습니다.
- **안전한 붙여넣기 (브라켓 페이스트)**: 여러 줄 코드를 붙여넣어도 엔터가 따로 눌리지 않고, 5KB 이상 큰 텍스트는 실수하지 않게 한 번 물어보고 붙입니다.
- **TUI 복사·링크·이미지까지 한 번에**:
  - 복사할 때 줄 끝 공백은 알아서 털어 줍니다.
  - 클립보드에서 이미지 탭 한 번으로 PNG 저장 + 경로 자동 입력.
  - `Ctrl` 누르고 화면의 URL을 누르면 브라우저로 바로 열립니다.
- **추가 앱 없는 알림 & 13개 언어**: `termux-api` 없이도 벨 소리와 알림이 울리고, 앱 언어는 13개국어를 지원합니다.
- **백그라운드 복원**: 앱을 닫았다 켜도 실행 중이던 화면과 마우스 모드가 그대로 살아납니다.

## 설치 방법

준비물은 간단합니다. **APK 설치**, **Termux에 한 줄 실행**, 그리고 **권한 3개 허용**.

1. [Releases](https://github.com/CrashedSystem/fterm/releases/latest)에서 **`fterm.apk`**를 받아 설치합니다.
2. **Termux**를 열고 아래 한 줄을 붙여넣어 실행합니다.

```bash
curl -fsSL https://raw.githubusercontent.com/CrashedSystem/fterm/master/termux/setup.sh | bash
```

3. **fterm**을 실행하고, 묻는 권한 3가지를 허용해 주세요.
   - **모든 파일 접근 권한**: 앱이 Termux 데몬과 토큰을 주고받기 위해 필요합니다.
   - **사진/이미지 권한**: 클립보드 스크린샷을 붙여넣기 위해 필요합니다.
   - **알림 권한**: 작업 완료 벨 알림을 띄우기 위해 필요합니다.

권한 허용 뒤 앱으로 돌아오면 자동으로 연결됩니다.

## 자주 쓰는 단축키

- **새 탭 / 탭 닫기**: `+` 버튼 / 탭 길게 누르기 (키보드 `Ctrl+Shift+T` / `W`)
- **설정 열기**: `+` 길게 누르기 (`Ctrl+,`)
- **탭 이동**: `Ctrl+Tab` / `Ctrl+1~9`
- **URL 바로 열기**: `Ctrl` + 화면 탭 또는 클릭
- **복사 / 붙여넣기**: `Ctrl+Shift+C` / `V`, 또는 화면 길게 누르기·우클릭
- **글자 크기**: `Ctrl+=` / `Ctrl+-` / `Ctrl+0`

## Termux, честно говоря, неудобен

- Чтобы поменять шрифт, цвет или одну лишнюю клавишу внизу, приходится открывать файл конфигурации (`termux.properties`).
- Чтобы переключить вкладку, каждый раз нужно свайпать боковую панель слева.
- В полноэкранных интерфейсах (TUI) вроде OpenCode клавиатура иногда просто не открывается.
- Корейский и другие языки съезжают, а вставить скриншот в промпт — целая морока.
- При вставке большого текста всё подтормаживает, а переносы строк разваливаются на отдельные Enter.
- Даже одно уведомление о завершении задачи требует отдельно установленного `termux-api`.

## fterm начался именно с этого

Оболочка осталась той же, из Termux, — **заново сделаны только экран и ввод, которые бесили.**

- **Вкладки перед глазами**: открывайте, переключайте, переименовывайте и раскрашивайте вкладки прямо в верхней панели, без свайпов.
- **Настройка без файлов конфигурации**: цветовые темы, шрифты (корейский и иконки уже внутри), фоновые изображения и нижняя панель клавиш меняются прямо в настройках приложения.
- **Готовые профили**: выберите оболочку или команду, которой пользуетесь чаще всего, и открывайте её сразу.
- **Современный и приятный интерфейс**: аккуратные иконки Fluent, вкладки в стиле Windows Terminal и CRT-эффект по желанию — ничего деревянного.
- **Безопасная вставка (bracketed paste)**: многострочный код вставляется без лишних Enter, а на тексте больше 5 КБ приложение один раз переспросит, чтобы не вставить случайно.
- **Копирование, ссылки и картинки в TUI — в одном месте**:
  - При копировании пробелы в конце строк убираются сами.
  - Одно касание картинки в буфере обмена сохраняет её в PNG и подставляет путь.
  - Удерживайте `Ctrl` и коснитесь URL на экране — он откроется в браузере.
- **Уведомления без лишних приложений и 13 языков**: звонок и уведомления работают без `termux-api`, интерфейс поддерживает 13 языков.
- **Восстановление в фоне**: закройте приложение и вернитесь — экран и режим мыши на месте.

## Установка

Нужно всего три вещи: **установить APK**, **выполнить одну строку в Termux** и **разрешить 3 разрешения**.

1. Скачайте **`fterm.apk`** из [Releases](https://github.com/CrashedSystem/fterm/releases/latest) и установите.
2. Откройте **Termux** и вставьте строку ниже, чтобы выполнить её.

```bash
curl -fsSL https://raw.githubusercontent.com/CrashedSystem/fterm/master/termux/setup.sh | bash
```

3. Запустите **fterm** и разрешите три запрошенных разрешения.
   - **Доступ ко всем файлам**: чтобы приложение обменивалось токеном с демоном Termux.
   - **Фото/изображения**: чтобы вставлять скриншоты из буфера обмена.
   - **Уведомления**: чтобы звенел звонок по завершении задачи.

Как только разрешите и вернётесь в приложение, соединение установится само.

## Полезные сочетания

- **Новая вкладка / закрыть вкладку**: кнопка `+` / долгое нажатие на вкладку (клавиатура `Ctrl+Shift+T` / `W`)
- **Открыть настройки**: долгое нажатие на `+` (`Ctrl+,`)
- **Переключение вкладок**: `Ctrl+Tab` / `Ctrl+1–9`
- **Открыть URL сразу**: `Ctrl` + касание или клик по экрану
- **Копировать / вставить**: `Ctrl+Shift+C` / `V`, либо долгое нажатие · правая кнопка мыши
- **Размер текста**: `Ctrl+=` / `Ctrl+-` / `Ctrl+0`
